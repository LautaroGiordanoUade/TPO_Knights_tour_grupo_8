# TPO - Knight's Tour (Grupo 8)

## Descripción del proyecto
Este proyecto desarrolla una solución al **Knight’s Tour**, un desafío clásico de ajedrez y teoría de grafos.  
El objetivo es encontrar un recorrido del caballo sobre un tablero de ajedrez de manera que visite **todas las casillas exactamente una vez**, sin repetir posiciones.

El trabajo fue realizado como TPO para Programación 3 de la **Universidad Argentina de la Empresa (UADE)**.

---

## Contexto teórico
El *Knight’s Tour* es un problema matemático que puede abordarse mediante distintas técnicas algorítmicas, entre ellas:

- **Backtracking:** búsqueda exhaustiva con retroceso.
- **Heurística de Warnsdorff:** estrategia que prioriza los movimientos con menos opciones futuras.

El proyecto busca comparar o implementar una o más de estas estrategias para resolver el problema en distintos tamaños de tablero.
